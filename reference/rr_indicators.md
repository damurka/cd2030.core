# Tabs of the reporting rate chart

The keys of the tabs of the first card on the reporting rate page
([`reporting_rate_ui()`](reporting_rate_ui.md)): the heat map and the
bar chart.

## Usage

``` r
rr_indicators
```

## Format

A character vector.

## Examples

``` r
rr_indicators
#> [1] "heat_map" "bar"     
```
