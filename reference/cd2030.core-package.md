# cd2030.core: Data Loading, Validation, and Reporting for Countdown 2030

cd2030.core is an R package for managing and validating data formatted
according to Countdown 2030 standards. It provides tools for data
loading, cleaning, and validation, detecting issues like missing values,
inconsistencies, outliers, and ratio anomalies. The package ensures
compliance with Countdown 2030 guidelines and generates standardized
data quality reports, enabling users to focus on analysis and
interpretation.
