# cd2030.core: Countdown to 2030 analysis of routine health facility data

Loads a country's routine facility data (the Countdown Excel workbook,
or a Stata `.dta` master file), checks its quality, adjusts it for
incomplete reporting and outliers, chooses denominators, and computes
coverage, inequality, mortality, service utilization, health system and
family planning indicators, with a chart
([`plot()`](https://rdrr.io/r/graphics/plot.default.html)) for each
result. The Countdown apps – cd2030.rmncah, cd2030.vaxx and
cd2030.pooled – are Shiny front ends to it, built from the pages, wizard
and app frame it exports, on datasuite.ui's interface kit and report
builder.

## Where to start

- **A dataset:** [`load_cache_data()`](load_cache_data.md) opens a
  workbook or a saved `.rds` as a [CacheConnection](CacheConnection.md),
  the object that holds one dataset and every choice made about it
  (adjustments, denominators, surveys, mappings, chart options, saved
  reports) and saves them to the `.rds` next to the data file.
  [`load_data()`](load_data.md) gives just the checked data;
  [`init_CacheConnection()`](init_CacheConnection.md) makes the object
  from data or an `.rds`.

- **Data quality:**
  [`calculate_average_reporting_rate()`](calculate_average_reporting_rate.md),
  [`calculate_completeness_summary()`](calculate_completeness_summary.md),
  [`calculate_outliers_summary()`](calculate_outliers_summary.md),
  [`calculate_ratios_summary()`](calculate_ratios_summary.md),
  [`calculate_overall_score()`](calculate_overall_score.md); the Load
  Data wizard's checks,
  [`run_all_quality_checks()`](run_all_quality_checks.md).

- **Adjustment:**
  [`generate_adjustment_values()`](generate_adjustment_values.md),
  [`adjust_service_data()`](adjust_service_data.md).

- **Denominators and coverage:**
  [`prepare_population_metrics()`](prepare_population_metrics.md),
  [`calculate_indicator_coverage()`](calculate_indicator_coverage.md),
  [`calculate_coverage()`](calculate_coverage.md),
  [`calculate_inequality()`](calculate_inequality.md).

- **Further analyses:**
  [`create_mortality_summary()`](create_mortality_summary.md),
  [`compute_service_utilization()`](compute_service_utilization.md),
  [`calculate_health_system_metrics()`](calculate_health_system_metrics.md),
  [`generate_fpet_summary()`](generate_fpet_summary.md),
  [`generate_bayes_model()`](generate_bayes_model.md).

- **Reports:** [`report_presets()`](report_presets.md) (the standard
  reports) and
  [`export_report()`](https://rdrr.io/pkg/datasuite.ui/man/export_report.html)
  (Word, PDF, PowerPoint).

- **Indicator groups:**
  [`list_indicator_groups()`](list_indicator_groups.md),
  [`set_selected_group()`](set_selected_group.md),
  [`register_indicator_group()`](register_indicator_group.md).

- **Apps:** [countdown-pages](countdown-pages.md)
  ([`cd_app()`](countdown-pages.md) and the pages every Countdown app
  shares).

The README (<https://github.com/damurka/cd2030.core>) explains how the
packages fit together, how an app is built on this one, and how to
develop and release it.
