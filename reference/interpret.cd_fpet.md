# Interpret FPET Results with Emphasis on Current Estimates

Summarizes 2020 and 2024 estimates, and briefly mentions FPET
projections to 2030.

## Usage

``` r
# S3 method for class 'cd_fpet'
interpret(x, ...)
```

## Arguments

- x:

  A `cd_fpet` object.

- ...:

  Unused.

## Value

A character string with interpretation summary.
