# Plot private sector prevalence by sector and area/national level

Generates a stacked bar chart for RMNCAH indicators comparing public vs.
private sector share by either national or area-level (urban/rural)
estimates.

## Usage

``` r
# S3 method for class 'cd_private_sector_plot_data'
plot(
  x,
  title = NULL,
  subtitle = NULL,
  caption = NULL,
  x_title = NULL,
  y_title = NULL,
  legend_title = NULL,
  ...,
  country_name = NULL,
  legend_labels = NULL,
  indicator_labels = NULL,
  area_labels = NULL,
  share_label = NULL,
  options = NULL
)
```

## Arguments

- x:

  A data frame of class `"cd_private_sector_plot_data"` generated by
  [`prepare_private_sector_plot_data()`](prepare_private_sector_plot_data.md).

- title:

  The chart's title.

- subtitle:

  The line under the title.

- caption:

  The note under the chart.

- x_title:

  The title of the horizontal axis.

- y_title:

  The title of the vertical axis.

- legend_title:

  The title of the legend.

- ...:

  Chart options by name (see
  [`cd_chart_options()`](https://rdrr.io/pkg/datasuite.ui/man/cd_chart_options.html)):
  background, fonts, sizes, axes, grid, legend, colours. Other arguments
  are ignored.

- country_name:

  Optional character string to override the default country name used in
  the plot title. If `NULL`, uses the unique value in the `country`
  column if present.

- legend_labels:

  (Optional) A named list to override the legend's entries, e.g. with
  translations: `public` and `private`.

- indicator_labels:

  (Optional) A named list of the indicators' names: `careany`,
  `csection` and `ideliv`.

- area_labels:

  (Optional) A named list of the areas' names, for area data: `rural`
  and `urban`.

- share_label:

  (Optional) The text written before the private share. By default
  `"Priv. share = "`.

- options:

  A
  [`cd_chart_options()`](https://rdrr.io/pkg/datasuite.ui/man/cd_chart_options.html)
  object or a list of chart options: a look made once, to give to
  several charts. Applied after the text arguments, so a text it holds
  wins over them.

## Value

A `ggplot` object with:

- Stacked bars for public/private sector share

- Facets by indicator for area-level plots

- Annotated private sector shares as text labels

## Details

The function automatically detects whether the data is at the
`"national"` or `"area"` level using the `"level"` attribute. It:

- Maps indicator codes to descriptive labels

- Stacks `r_raw_Public` and `r_raw_Private` values

- Adds text annotations for private sector shares

For area-level data, bars are grouped by `area` and faceted by
indicator. For national-level data, each indicator has a single stacked
bar.
