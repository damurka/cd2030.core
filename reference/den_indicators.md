# Tabs of the denominator assessment chart

The keys of the tabs on the denominator assessment page
([`denominator_assessment_ui()`](denominator_assessment_ui.md)): total
population, births and children under one.

## Usage

``` r
den_indicators
```

## Format

A character vector.

## Examples

``` r
den_indicators
#> [1] "population" "births"     "under1"    
```
