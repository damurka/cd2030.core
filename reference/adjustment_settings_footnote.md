# What the adjustment settings say, as the reports' footnote

What the adjustment settings say, as the reports' footnote

## Usage

``` r
adjustment_settings_footnote(
  settings,
  group_labels = NULL,
  indicator_labels = NULL
)
```

## Arguments

- settings:

  The settings list.

- group_labels, indicator_labels:

  Named character: how groups and indicators are called (by default
  their ids).

## Value

A character vector, one sentence per rule (none for the Countdown
default).
