# Plot FPET Estimates

Creates a line plot for modern contraceptive prevalence rate (mCPR) over
time, optionally faceted by subnational region.

## Usage

``` r
# S3 method for class 'cd_fpet'
plot(x, ...)
```

## Arguments

- x:

  A `cd_fpet` object.

- ...:

  Additional arguments for customization (not used).

## Value

A ggplot2 object.
